# Web Data Schema

JSON read by `web/api.py` from the active data directory:

1. `$LEXIFORGE_WEB_DATA` if set,
2. `web/data/` when it contains `calls.json` (measured export),
3. `web/data/sample/` (labelled placeholder).

Files are re-read when their mtime changes; missing files fall back to empty
defaults with a warning and never crash the service.

## Provenance

Every dataset must state what it is.

`demo_config.json`

```json
{
  "mode": "precomputed",
  "data_source": "measured",
  "merge": "none",
  "redacted": true,
  "redaction_counts": { "[PHONE]": 3, "[NUMBER]": 1 },
  "note": "Generated by scripts/export_web_data.py from scored transcripts."
}
```

`data_source` is `"measured"` or `"illustrative_sample"`. `GET /meta` derives
`is_sample` from it and the front end shows a banner when it is true.

`redacted` records whether the exporter masked PII. `redaction_counts` is the
tally written by the run, so a reviewer can see that masking actually happened
rather than trusting a flag.

`results.json` repeats the marker at the top level (`"source"`, `"is_sample"`)
so the file is self-describing outside the service.

## calls.json

Array of call objects.

```json
[
  {
    "call_id": "c01",
    "call_type": "upi_failed",
    "duration_s": 18.5,
    "has_audio": true,
    "n_conditions": 4
  }
]
```

## transcripts.json

Mapping of `call_id` to one token array per condition. Only conditions that were
actually run appear; the API returns exactly those keys.

```json
{
  "c01": {
    "baseline": [{ "text": "mera", "status": "same" }],
    "mismatched-200": [{ "text": "insurance", "status": "inserted" }]
  }
}
```

Token statuses (computed by `scripts/export_web_data.py`, not by the UI):

- `same` — unchanged text
- `recovered` — glossary span present in the hypothesis and in the reference
- `inserted` — glossary span in the hypothesis with no matching reference term
- `missed` — reference term not produced (only used by curated datasets; the
  exporter reports these separately under `terms.json` because they have no
  hypothesis text to render)

## terms.json

Mapping of `call_id` to the selector's context list.

```json
{
  "c01": {
    "selected": [{ "term": "UPI", "term_id": "R0012", "source": "lex", "score": 0.71 }],
    "left_out": ["IFSC", "KYC"],
    "missed_by_condition": { "baseline": ["NEFT"] }
  }
}
```

`source` is `lex` or `phon` (whichever component dominated). `score` is the
selector's `S` value. `missed_by_condition` is optional.

## results.json

```json
{
  "source": "measured",
  "is_sample": false,
  "note": "Descriptive paired differences. Run lexiforge.analysis.inference for p-values.",
  "contrasts": [
    {
      "name": "mismatched-200 vs baseline (real-term recall)",
      "kind": "h1",
      "unit": "pp",
      "delta_pp": -12.5,
      "ci_low": -18.3,
      "ci_high": -6.7,
      "p_holm": 0.012,
      "n_calls": 20,
      "verdict": "supports H1"
    }
  ],
  "control": { "baseline_recall": 0.92 }
}
```

`kind` is `h1`, `h2`, `control` or `exploratory`. `ci_low`/`ci_high`/`p_holm` are
optional: the bundled exporter emits descriptive differences only, and the UI
renders `—` when an interval or p-value is absent rather than inventing one.

## meta (not a file)

`GET /meta` is derived, never stored:

```json
{
  "data_source": "measured",
  "is_sample": false,
  "note": "...",
  "mode": "precomputed",
  "conditions": ["baseline", "mismatched-200"],
  "call_count": 20,
  "audio": ["c01", "c03"]
}
```

`audio` lists call ids whose recording resolves under `LEXIFORGE_AUDIO_DIR`
(default `audio/`). The call page probes `/calls/{id}/audio` with `HEAD` before
showing a player, so a missing recording renders nothing rather than a broken
control.
